## [Keyv 及相关 npm 包在 Shai-Hulud 供应链攻击中遭入侵](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack) ⭐️ 9.0/10

npm 包 keyv 和 cacheable 在 Shai-Hulud 供应链恶意软件的新一轮攻击中遭到入侵。该恶意软件窃取凭证、如蠕虫般传播至其他包，并在 GitHub 仓库中植入执行钩子。 这次攻击暴露了 npm 依赖链中脆弱的信任模型——一个维护者账户被入侵就能波及数千个下游项目——并加剧了限制常被利用的预安装钩子的呼声。 Shai-Hulud 恶意软件是一种自我繁殖的蠕虫，会自动将自身发布到被入侵账户有写入权限的每个 npm 包上，并植入 GitHub Action 钩子以持久化。它主要滥用预安装脚本在包安装期间执行恶意代码。

hackernews · cimi_ · 8月4日 11:01 · [社区讨论](https://news.ycombinator.com/item?id=49166874)

**影响**: 短期内，依赖 keyv 的开发者可能凭证失窃，400 多个包会直接受到影响。长期来看，这可能会加速 npm 中预/后安装脚本的弃用，并推动最低包龄等安全策略的采用，重塑 JavaScript 生态的开源供应链安全实践。

**背景**: Keyv 是一个广泛使用的 npm 模块，用于简单的键值存储，有 1700 多个依赖项目。供应链攻击利用软件依赖中的信任关系；npm 的预安装和后安装钩子允许在包安装时执行任意代码，使其成为常见的攻击媒介。Shai-Hulud 攻击是近年来继 s1ngularity 和维护者 Qix 遭入侵之后的第三波重大 npm 供应链攻击。

## [我国首部 L3/L4 自动驾驶强制性国标发布，2027 年 7 月起实施](https://wap.miit.gov.cn/jgsj/zbys/qcgy/art/2026/art_a1d2072374884287b67048a77560014e.html) ⭐️ 9.0/10

工业和信息化部正式批准发布了强制性国家标准《智能网联汽车 自动驾驶系统安全要求》（GB 44721—2026），将 2024 年的推荐性标准升级为具有约束力的法规，针对 L3 级有条件自动驾驶和 L4 级高度自动驾驶系统，将于 2027 年 7 月 1 日起实施。 这是我国首个针对高级别自动驾驶的强制性国家标准，标志着法规层面的里程碑，为 L3/L4 系统提供了明确的法律基准和安全要求，对推动其从测试走向公开商业化至关重要。 该标准适用于 M 类（载客）和 N 类（载货）车辆，但明确不包括自动泊车系统。它要求自动驾驶系统的安全水平至少达到合格且专注驾驶人的水平，涵盖企业全生命周期安全保障、系统动态驾驶能力、人机交互与用户告知、多维度检验检测四个维度。

telegram · zaihuapd · 8月4日 13:06

**影响**: 短期内，汽车制造商和供应商必须在 2027 年中前使系统符合新标准，这将加速开发与合规进程。长期来看，这一强制要求将增强消费者信任，推动保险和责任框架的建立，并可能使中国成为全球自动驾驶法规的引领者，同时迫使小型企业整合或退出市场。

**背景**: 根据《汽车驾驶自动化分级》，L3 级（有条件自动驾驶）在特定条件下由车辆执行动态驾驶任务，但驾驶员需随时接管；L4 级（高度自动驾驶）在限定区域内无需人类干预。M 类车辆主要用于载客，N 类车辆用于载货。此前的 2024 年标准仅为推荐性，缺乏强制力，限制了广泛采用。
