## [TileRT Software Enables Ultra-Low Latency Inference on NVIDIA GPUs](https://newsletter.semianalysis.com/p/ultra-high-interactivity-on-nvidia) ⭐️ 8.0/10

TileRT, a new tile-level runtime engine, enables NVIDIA GPUs to achieve ultra-low latency inference for large language models, challenging specialized hardware like Cerebras CS-3 and Groq LPU. This software innovation demonstrates that commodity NVIDIA GPUs can potentially match or exceed the inference latency of proprietary accelerators, democratizing high-interactivity AI services without requiring specialized hardware. TileRT achieves ultra-low latency by using a tile-based runtime that separates prefill and decode phases across different GPUs (disaggregated serving), and it has been publicly released for the DeepSeek-V3.2-Exp model, with packages on PyPI and HuggingFace.

rss · Semianalysis · Aug 10, 04:51

**Impact**: In the short term, it allows businesses to achieve low-latency serving using existing GPU clusters, lowering costs. Over time, it could reshape the AI inference market by making software-driven optimizations a viable alternative to specialized chips, potentially reducing demand for accelerators like Cerebras or Groq and intensifying competition among GPU cloud providers.

**Background**: Large language model inference has two phases: prefill, which processes the entire prompt at once, and decode, which generates tokens sequentially. Disaggregated serving assigns these phases to separate hardware, optimizing each for its specific needs. Specialized accelerators like Cerebras (wafer-scale chips) and Groq LPUs are purpose-built for low-latency inference, while NVIDIA GPUs have been less optimized for this use case until now.

## [Hand-crafted transformer weights achieve perfect 100% multiplication accuracy](https://www.reddit.com/r/MachineLearning/comments/1vkrnb5/transformers_are_famously_bad_at_arithmetic_so_i/) ⭐️ 8.0/10

A developer manually set transformer weights using a custom compiler to perform exact grade-school multiplication, achieving 100% accuracy on up to 12-digit numbers without any training. The model, based on Phi-3, outperforms frontier models on arithmetic tasks. This demonstrates that transformer architectures have inherent computational capabilities that can be directly programmed, bypassing learned approximations. The weights were compiled from a grade-school multiplication algorithm using Torchwright, a custom compiler. Four versions were implemented, trading off layers, width, generated tokens, and parameters. The model achieves 100% on all 3,000,000 supported expressions for 3-digit multiplication, with checkpoints for up to 12-digit multiplication available.

**Impact**: Short-term, it provides a benchmark for evaluating learned models' arithmetic reasoning and a tool for studying transformer expressiveness. **Background**: Transformers are the backbone of large language models but often struggle with multi-digit arithmetic due to the difficulty of learning exact algorithms from data. Prior work like ALTA has shown that algorithms can be compiled into transformer weights, but this demonstration focuses on achieving perfect accuracy without training, using a hand-crafted approach.
