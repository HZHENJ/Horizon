## [OpenAI 发布 ChatGPT Images 2.5，生成更快更清晰](https://openai.com/index/introducing-chatgpt-images-2-5/) ⭐️ 9.0/10

OpenAI 于 2026 年 9 月 8 日发布 ChatGPT Images 2.5，并在 ChatGPT、ChatGPT Work 和 Codex 全平台上线；新模型细节更清晰、编辑更精准，图像生成延迟较 2.0 版本最高降低 50%。同时在 ChatGPT 中新增 Sketch 手绘引导、模板、图片评论和提示词分享功能，API 推出 GPT-Image-2.5 Flare 和 Sunburst 两款模型。 ChatGPT Images 是广泛使用的 AI 图像生成工具，OpenAI 表示用户每周通过 ChatGPT Images 和 GPT-Image API 生成超过 30 亿张图像，因此将生成延迟从约 104 秒降低到 35 至 40 秒是重大体验提升。这一发布表明 OpenAI 在竞争激烈的 AI 图像市场中优先改进迭代速度，而快速反馈循环正变得越来越重要。 本次更新包含两款新 API 模型：GPT-Image-2.5 Flare 和 Sunburst，并在 ChatGPT 界面中新增 Sketch 手绘引导、模板、图片评论和提示词分享功能。一位使用 GPT-Image-2 生成约 5 万张图像的社区开发者报告，新版本平均延迟从 104 秒降至 35 至 40 秒，与 OpenAI 所称较 2.0 最高降低 50% 的说法一致。

hackernews · vertigoruntime · 9月8日 18:37 · [社区讨论](https://news.ycombinator.com/item?id=49614720)

**影响**: 短期内，使用该 API 的开发者与设计师——例如进行 AI UI 设计工具迭代的团队——将获得更快响应，社区实测显示生成延迟从约 104 秒降至 35 至 40 秒，同样的时间内可以进行更多实验。创作型用户在进行插画、原型或个人项目时，也能从更快的编辑和新增的提示词分享功能中受益。长期来看，这种速度提升可能加速 AI 图像模型在生产设计流程中的采用，并对其他图像生成器在延迟和编辑精度上形成竞争压力。

**背景**: ChatGPT Images 是 OpenAI 内置于 ChatGPT 中并通过 API 提供的图像生成服务，用户可以通过文本提示生成和编辑图像。此前于 2026 年发布的 2.0 版本引入了更好的文字渲染、多语言支持和高级视觉推理，并提供基于选区编辑和宽高比控制等工具。2.5 版本在此基础上进一步改进，重点提升生成速度和细节精度，同时扩展编辑与协作功能。

## [“i-have-adhd”技能让编程代理不再埋没答案](https://github.com/ayghri/i-have-adhd) ⭐️ 8.0/10

新的开源技能“i-have-adhd”已在 GitHub 上发布，它指导编程代理把行动放在首位、使用编号步骤，避免把答案埋在冗长输出中。 冗长的 LLM 输出浪费时间和 token，Claude 尤其常因埋没答案而被点名；该技能是应对 Claude 写作风格的不断增长的提示工程变通方案的一部分，反映了对简洁、ADHD 友好通信的需求。 该技能以 markdown 指令集（SKILL.md）形式分发，可放在 .cursor/skills 中或通过 CLI 引用；它要求行动优先、编号步骤，但用户报告其简洁效果几轮后可能减弱，需重复提醒。

hackernews · domhudson · 9月8日 14:13 · [社区讨论](https://news.ycombinator.com/item?id=49610631)

**影响**: 短期内，使用 Claude Code、Cursor 等兼容代理的开发者可以获得更直接、行动优先的回答，减少 token 消耗。长期来看，这类技能可能影响代理界面处理冗长问题的方式，但社区反馈显示，若不反复强化，Claude 几轮后可能恢复啰嗦风格。

**背景**: Claude Code、Cursor 等编程代理可通过“技能”进行定制——这些是可自动应用于相关任务的可复用 markdown 指令。ADHD 友好的格式意味着答案先行、使用编号步骤、避免不必要的限定或离题。Claude 等 LLM 模型常因冗长、回避式回答而受到批评，把用户要求的行动埋在大量文本中。
