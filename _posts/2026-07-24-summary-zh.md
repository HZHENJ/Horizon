## [Anthropic 发布 Claude Opus 5：无数据保留要求的企业级 AI](https://www.anthropic.com/news/claude-opus-5) ⭐️ 10.0/10

Anthropic 发布了其迄今最强大的模型 Claude Opus 5，具备先进的推理和视觉能力。值得注意的是，该模型在一般访问中不要求数据保留，这与某些早期模型不同。 该发布通过取消数据保留，消除了企业采用的主要障碍，使组织能够在不损害数据隐私的情况下使用最先进的 AI。这标志着行业向更注重隐私的 AI 服务转变。 Opus 5 的数据保留政策表示：‘与之前的 Opus 模型一致，Opus 5 在一般访问中没有数据保留要求。’社区测试显示，在图像转 HTML 等任务中，其准确性比 Fable 有所提高。

**影响**: 短期内，之前因隐私政策而犹豫的企业现在可以立即将 Opus 5 整合到工作流程中，加速 AI 采用。长期来看，此举将迫使其他 AI 提供商放宽数据保留政策，重塑竞争格局。开发者也能立即获得尖端的多模态性能，用于图像转代码等应用。

**背景**: Claude Opus 是 Anthropic 性能最强的模型系列，早期版本有 Opus 4.8。数据保留政策决定用户输入是否被存储用于模型改进等；许多企业要求零保留以确保合规。多模态 AI 模型能处理文本和图像，而系统卡如同营养标签，记录模型能力和局限性，以增强透明度。

## [安全摄像头在登录页面泄露 GitHub 管理员令牌](https://hhh.hn/hanwha-github-token/) ⭐️ 9.0/10

一款安全摄像头的登录页面被发现包含了一个硬编码的 GitHub 个人访问令牌，该令牌具有管理员权限，从而泄露了供应商的内部代码库和基础设施。 该事件凸显了物联网设备中严重的安全疏忽，硬编码凭证可能授予版本控制系统完全的管理访问权限，从而可能危及源代码和供应链完整性。 该令牌是一个具有管理员权限范围的 GitHub 个人访问令牌，可能嵌入在摄像头的网页界面中，通过查看页面源代码即可发现。虽然令牌可以被撤销，但硬编码机密的做法仍然是一个普遍存在的漏洞。

hackernews · hhh · 7月24日 11:54 · [社区讨论](https://news.ycombinator.com/item?id=49034292)

**影响**: 短期来看，泄露的令牌可能允许未经授权访问供应商的 GitHub 仓库，存在数据盗窃或恶意代码注入的风险。长期而言，这会削弱消费者对物联网安全的信任，并可能加速对监管标准和联网设备强制安全审计的需求。

**背景**: GitHub 个人访问令牌用于认证 API 请求并授予特定权限，例如仓库访问或组织管理。硬编码凭证是指将密码或令牌直接嵌入源代码中，这是一种危险的做法，如果代码公开或可访问，就会泄露机密。在物联网领域，由于安全标准松散和开发周期紧张，此类缺陷很常见。

《科学》杂志独家调查披露，一名 6 岁女童于 2025 年 3 月在上海一家医院接受绕过国家监管的实验性碱基编辑基因治疗后死亡，且该事件在后续《自然》论文中未予披露。 此案暴露了中国基因疗法监管的重大漏洞，通过'医院豁免'规避临床试验规定，并凸显了缺乏透明度会损害科学诚信和患者安全。 该疗法通过向脊髓液注射数万亿携带碱基编辑器的 AAV 病毒载体，靶向脑部神经元，但七天内引发致命免疫反应。该试验在 ClinicalTrials.gov 上的记录已一年多未更新。

## [英伟达、微软、Meta 联合警告勿过度监管开源权重 AI](https://www.cnbc.com/2026/07/24/nvidia-microsoft-meta-open-weight-ai-models.html) ⭐️ 8.0/10

英伟达、微软和 Meta 联合发布公开信，警告对开放权重 AI 模型的过度监管将损害创新和美国竞争力。 开放权重模型通过允许研究人员和初创公司基于现有成果进行开发来推动创新；过度监管可能会将权力集中到少数闭源 AI 提供商手中，扼杀竞争和伦理 AI 发展。 公开信可在英伟达官网获取（images.nvidia.com/pdf/Open-Weights-and-American-AI-Leadership.pdf）。这场辩论恰逢 Anthropic 据报道投入 4000 万美元政治捐款以影响模型监管，以及围绕中国 AI 模型的更广泛分歧。

hackernews · louiereederson · 7月24日 13:32 · [社区讨论](https://news.ycombinator.com/item?id=49035303)

**影响**: 短期内，这可能加剧 AI 监管辩论双方的游说力度，OpenAI 和 Anthropic 等公司主张限制，而其他公司则倡导开放。长期来看，如果限制性政策得以实施，开放权重生态系统——包括 Meta 的 Llama 和 DeepSeek 等模型——可能面临障碍，减缓 AI 民主化进程，并可能让快速发展的中国开放权重模型占据优势。

**背景**: 开放权重模型，如 Meta 的 Llama 或 DeepSeek V4，具有可公开下载的参数，允许在不获取训练数据或代码的情况下进行微调和部署。它们与完全开源的 AI 有所不同。美国及其他政府正在考虑对 AI 模型实施新的出口管制和法规，部分原因是出于对滥用和中国竞争的担忧。同时，OpenAI 和 Anthropic 等闭源 AI 公司认为无限制访问会带来安全风险。
