Tailscale published a transparent post-mortem revealing that the recent Hugging Face security incident was caused by a reusable auth key exposed in an environment file, which allowed an attacker to enroll 181 unauthorized nodes into Hugging Face's tailnet over several days. This incident underscores that zero-trust security tools cannot compensate for operational lapses; proper configuration hygiene—such as avoiding long-lived reusable keys—is critical, as a single exposed credential can undermine network security. The exposed reusable auth key was not time-limited, allowing prolonged misuse, and the attacker used the '--no-logs-no-support' flag to suppress telemetry, making detection more difficult.

hackernews · bluehatbrit · Jul 31, 19:03 · [Discussion](https://news.ycombinator.com/item?id=49127306)

**Impact**: Short-term, Hugging Face had to revoke keys, remove rogue nodes, and audit access, while facing scrutiny over its security practices. Long-term, organizations are likely to tighten key management, adopt one-off or short-lived keys, and enable telemetry for better visibility. Tailscale may see increased emphasis on its security features and secure configuration guidance.

**Background**: Tailscale is a mesh VPN implementing zero-trust networking, where devices authenticate via auth keys to join a 'tailnet'. Reusable keys, convenient for CI/CD, can be used multiple times, posing a risk if exposed. Hugging Face, a leading AI model platform, was a high-value target. Zero-trust principles demand 'never trust, always verify,' which failed due to the exposed key.

## [Huawei Open-Sources 505B-Parameter MoE Model openPangu-2.0-Pro](https://huggingface.co/openpangu/openPangu-2.0-Pro) ⭐️ 8.0/10

Huawei released openPangu-2.0-Pro, a 505-billion-parameter Mixture-of-Experts (MoE) language model with 18 billion activated parameters per token, trained on 34 trillion tokens using Ascend NPUs, and achieving 95.4 on AIME 2026 and 87.9 on GPQA-Diamond in its thinking version. This release marks one of the largest openly available MoE models, showcasing competitive performance on proprietary hardware, which challenges the dominance of NVIDIA GPUs and promotes AI development on alternative silicon. The model employs Multi-Head Latent Attention (MLA), a hybrid of DSA and SWA attention layers, and a 3-head Multi-Token Prediction (MTP) module for self-speculative decoding. telegram · zaihuapd · Jul 31, 06:50

**Background**: Mixture-of-Experts (MoE) is a model architecture where only a subset of parameters are active for each input, enabling high total parameter counts with lower compute per token.
