## [Qwen 发布 2.4 万亿参数开源权重 MoE 模型](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) ⭐️ 9.0/10

Qwen 已在 Hugging Face 发布 Qwen3.8-2.4T-A95B，这是一个仅文本的开源权重混合专家模型，总参数 2.4 万亿、激活参数 950 亿。其原生上下文长度为 262,144 个 token，可扩展至 1,010,000 个 token，但所有交互都必须使用思考模式。 这是迄今最大、能力最强的开源权重模型之一，将接近前沿的性能带入开放生态，并与 Kimi K3、DeepSeek V4-Pro 等模型直接竞争。该发布加速了开放稀疏 MoE 架构的趋势，以较低的每 token 计算成本实现高能力。 该模型仅支持文本输入，不支持多模态输入，且无法关闭思考模式。目前仅发布了 BF16 和 FP8 权重，尚无 QAT Q4 检查点；许可证允许内部使用或年收入低于 5000 万美元的服务免费使用，超过该门槛则有额外限制。

hackernews · Philpax · 8月12日 15:01 · [社区讨论](https://news.ycombinator.com/item?id=49273478)

**影响**: 短期内，开发者和研究人员可以下载并试验该模型，但完整 BF16 检查点需要约 4.9 TB 内存，因此实际使用仅限于资源充足的实验室和云服务商。社区的量化努力（如 Unsloth 的 1-bit 版本，大小 397 GB、激活参数 950 亿）可能让接近 Opus 4.5 的性能在高端消费级硬件上可用。长期来看，宽松但有上限的许可证（内部使用或年收入低于 5000 万美元免费）可能影响商业采用，并促使其他实验室发布类似规模的开源模型。

**背景**: 混合专家（MoE）模型将大型神经网络拆分为多个“专家”模块，路由器为每个 token 只激活其中的一部分。这使得巨大的总参数量（此处为 2.4 万亿）能够提供广泛知识，同时每个 token 的计算量仅取决于小得多的激活参数（此处为 950 亿）。Qwen 是阿里巴巴的大语言模型系列，开源权重发布允许任何人在指定许可证下下载、运行或微调权重。

## [研究人员从 OpenAI、Anthropic 和谷歌 API 中窃取加密推理轨迹](https://simonwillison.net/2026/Aug/11/stealing-reasoning-traces/) ⭐️ 9.0/10

新论文显示，OpenAI、Anthropic 和谷歌 API 返回的加密思维链块可在会话、用户和模型之间重放；研究人员将这些块喂给较弱的同系列模型并越狱，从而以明文恢复了更强模型的隐藏推理。相关提供商已确认收到报告，并已阻止同样的攻击。 这暴露了用于保护专有推理轨迹的安全机制存在重大漏洞，而这些轨迹通常因 AI 安全和竞争原因被隐藏。这表明加密思维链保护可在不直接访问前沿模型的情况下被绕过，引发对整个生态系统中透明度、隐私和模型提取的担忧。 该攻击依赖于同一系列中的所有模型共用相同的加密密钥；Claude Haiku 4.5 最容易受攻击，可通过设置助手回复前缀<thinking-copy>并配合要求逐字转录推理的提示来利用。论文附录包含提取到的原始推理轨迹，例如 GPT-5.5 规划 CSS 和 Svelte 组件的内容，以及一种让模型在思考中考虑外泄数据的提示注入变体。

rss · Simon Willison · 8月11日 22:40

**影响**: 短期内，这一披露可能迫使 OpenAI、Anthropic 和谷歌轮换或隔离加密密钥，并重新设计思维链处理方式；用户和 API 客户已无法再用演示方法提取隐藏推理。长期来看，它可能加速行业采用按会话或按请求加密以及更严格的跨模型隔离，同时让研究者和竞争对手得以窥见前沿模型的原始推理，可能有助于提示注入防御和模型对齐。

**背景**: 思维链提示让大语言模型在给出最终答案前生成中间推理步骤。提供商通常会在 API 响应中隐藏或加密这些推理块，以保护安全并防止竞争对手复制专有推理。前沿模型是指能力最强、最先进的通用 AI 模型，其原始推理可能包含敏感信息，因此提供商向客户端返回的是加密内容而非明文。

## [DeepSeek V4 Pro 0813：1.6T MoE 旗舰模型正式发布](https://openrouter.ai/deepseek/deepseek-v4-pro-0813) ⭐️ 8.0/10

DeepSeek 于 2026 年 8 月 12 日发布了 DeepSeek V4 Pro 0813，作为此前预览版 V4 Pro 的正式版本；API 调用 deepseek-v4-pro 现在会路由到 0813 构建。该模型是一个大规模混合专家（MoE）模型，上下文窗口为 1,048,576 个 token，最大输出为 384,000 个 token。 该版本延续了 DeepSeek 以远低于同行的成本提供接近前沿性能的模式，输入价格为每百万 token 0.435 美元，输出为每百万 token 0.87 美元。其重要性在于，一个据称 1.6T 参数的 MoE 旗舰模型正式结束预览，加剧了 AI 模型供应商之间的性价比竞争，并让长上下文能力更容易获得。 OpenRouter 列出的价格为每百万输入 token 0.435 美元、每百万输出 token 0.87 美元，上下文窗口为 1,048,576 个 token，最大输出为 384,000 个 token。社区分享的基准表格显示，DeepSeek V4 Pro 0813 在无工具的 HLE 测试中得分为 42.7/60.0；有用户指出它比 Opus 4.8 便宜约 20 倍，但弱于 Sol 或 Fable。

hackernews · explosion-s · 8月12日 16:04 · [社区讨论](https://news.ycombinator.com/item?id=49274600)

**影响**: 短期内，使用 DeepSeek API 或 OpenRouter 的开发者无需更改 API 名称即可直接使用新的 0813 构建，并从更低的价格和长上下文中受益，适合编码和长文档任务。长期来看，这一版本可能会促使其他供应商降低价格或改进长上下文产品，并加速 DeepSeek 模型在成本敏感的生产应用中的采用。社区测试表明，在复杂的多服务部署任务中仍存在一些可靠性问题，因此团队在关键工作负载上可能仍需将其与 GPT-5.6-Terra-High 或 Grok 4.6 等模型进行对比评估。

## [Zed 推出 Delta：将实时多人 AI 对话变成可编辑文档](https://zed.dev/blog/introducing-delta) ⭐️ 8.0/10

Zed 推出了 Delta，这是一项新功能，让用户能在编辑器内以可编辑文档的形式进行实时多人 AI 对话；参与者可以加入实时线程并对智能体交互进行行内评论。 Delta 将 AI 会话变成可共享、可检查的文档，填补了团队工作流中智能体生成代码只能在事后审查的空白；它将 AI 辅助编码与实时协作和指导联系起来。 Delta 基于 DeltaDB 构建，这是一种基于增量的本地存储引擎，记录增量更改而非完整快照；Zed 计划稍后将 DeltaDB 引入主编辑器，Delta 是第一个使用这些原语的产品。早期反馈指出，AI 摘要可能冗长且会遗漏边缘情况，不过 Delta 的文档式对话允许行内评论智能体交互。

hackernews · khy · 8月12日 18:19 · [社区讨论](https://news.ycombinator.com/item?id=49276574)

**影响**: 短期内，Zed 用户可以通过加入实时智能体线程并评论决策来指导初级工程师，在 Pull Request 之前提高代码质量。长期来看，如果 DeltaDB 成为 Zed 的存储层，团队可能会更少依赖事后的 PR 评论，而更多依赖持久化、版本化的智能体会话；这可能促使其他编辑器采用基于文档的 AI 协作方式。

**背景**: Zed 是一个用 Rust 编写的开源代码编辑器，强调速度与多人协作，并提供部分收费的 AI 功能。传统的 Pull Request 只在代码提交并推送后才附加审查评论，可能使讨论与原始推理脱节。DeltaDB 是 Zed 的新存储方案，以增量方式记录更改，可高效跟踪智能体会话历史。

## [Tailscale 追查数据库损坏根源：16 年前的 SQLite WAL-Reset 缺陷](https://tailscale.com/blog/sqlite-wal-reset-bug) ⭐️ 8.0/10

Tailscale 发现其控制平面数据库损坏是由 SQLite WAL-reset 逻辑中的竞态条件引起的，该缺陷据估计已存在至少 16 年。该公司资助了一个开源 SQLite VFS 封装层来跟踪文件操作，最终帮助定位了这一竞态条件。 这一发现表明，即使是 SQLite 这样成熟且广泛信赖的软件，也可能隐藏超十年之久的细微数据损坏缺陷；它也体现了定向调试工具以及企业资助开源维护的价值。这为 SQLite 的测试与可靠性理念增添了一个重要案例。 该竞态条件仅在多个进程或连接同时访问同一 WAL 模式数据库时才会发生，这起初与 Tailscale 的单写入者设计看似矛盾。该 VFS 封装层通过包装 SQLite 的操作系统接口并记录 VFS 调用，揭示了触发损坏的确切调用顺序。
