## [ChainDrop 蠕虫感染逾 1300 个 npm 包](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 9.0/10

名为 ChainDrop 的自传播蠕虫已入侵 1300 多个 npm 包，包括 Keyv 和 Cacheable 等热门缓存工具。攻击者通过劫持维护者的 GitHub 账号，利用 GitHub Actions 窃取凭证并扩散恶意代码。 这是 npm 历史上最大规模的供应链攻击之一，影响的包月下载量总计超过 20 亿次，突显了维护者账号失陷与自动化 CI/CD 流程结合带来的严重风险。 恶意软件通过 setup.mjs 和 Math_Symbol.js 在 npm install 时运行，窃取 GitHub、npm、AWS 和 Kubernetes 等凭证。命令与控制域名 npm-cache[.]com 可作为失陷指标。

telegram · zaihuapd · 8月5日 03:04

**影响**: 安装过受影响版本的开发者必须假设系统已被攻破，立即轮换所有令牌和凭证并重建环境。该事件预计将加速行业推行强制性多因素认证，并对软件包仓库实施更严格的供应链安全措施。

**背景**: 供应链攻击通过入侵软件流水线中安全性较低的环节，进而危害下游用户。GitHub Actions 是用于自动化构建、测试和部署的 CI/CD 服务，在此次攻击中被滥用，使攻击者能够发布带有合法来源签名的恶意包。

## [Cloudflare 推出开源 AI 代理与工作应用平台 Cloudflare OS](https://blog.cloudflare.com/cloudflare-os/) ⭐️ 8.0/10

Cloudflare 发布了 Cloudflare OS，这是一个开放平台，允许开发者在 Cloudflare Workers 无服务器基础设施上构建 AI 代理和协作式工作应用，其设计理念源自十年前的 Sandstorm 项目。 这次发布标志着 Cloudflare 正式进军 AI 代理基础设施市场，将边缘计算与可定制的 AI 工作流融合在一起。该平台的开放性可能吸引那些对封闭生态系统持谨慎态度的开发者，但潜在的供应商锁定风险仍是争议焦点。 Cloudflare OS 运行在 Cloudflare Workers 上，利用 Durable Objects 实现有状态协作，但跨自定义代理扩展管理共享数据模型仍是一项技术挑战。该平台被描述为“开放”，但具体的许可条款和最终的供应商中立可移植性尚未详细说明。

hackernews · speckx · 8月5日 13:58 · [社区讨论](https://news.ycombinator.com/item?id=49182996)

**影响**: 短期内，已有的 Cloudflare Workers 开发者将快速尝试构建内部 AI 工具，这可能加速 Workers 的采用。长远来看，如果 Cloudflare OS 获得发展势头，可能迫使 AWS Lambda 或 Vercel 等竞争对手提供类似的面向代理的平台，从而重塑无服务器在 AI 应用中的使用方式。然而，对供应商锁定和数据迁移的担忧可能会在没有明确迁移路径的情况下限制企业采用。

**背景**: Cloudflare Workers 是一种无服务器计算平台，能在靠近用户的边缘位置运行代码，降低延迟。Workers AI 提供无需管理 GPU 的 AI 推理能力。Cloudflare OS 在此基础上构建，为 AI 驱动的代理和协作应用提供更高级框架，其在精神上类似于已终止的 Sandstorm.io 项目，后者旨在让 Web 应用更易于自行托管和集成。
