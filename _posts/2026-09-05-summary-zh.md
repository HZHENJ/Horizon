## [声明式注意力让语言模型控制自身注意力](https://www.reddit.com/r/MachineLearning/comments/1w7sgf3/language_models_can_control_their_own_attention_r/) ⭐️ 8.0/10

这篇论文提出声明式注意力（Declarative Attention, DA）协议，让模型在思维链中用 <global>、<focus>、<local> 三种模式声明需要关注的区域。在 15 个长上下文任务上零样本评估，Gemma-4-31B 和 Qwen-3.6-27B 的解码期关注 token 数分别减少 52.0% 和 31.1%，准确率仅下降 1.27 和 2.75 个百分点。 与仍需每步 O(N) 开销的外部代理评分不同，DA 利用模型自身知识跳过无关的 KV cache 读取，从本质上降低长上下文推理成本。同时，它也为稀疏注意力开辟了固定或学习模式之外的新方向。 三种生成模式为 <global>（全上下文）、<focus>（特定区域）和 <local>（仅近期输出）；推理引擎像解析工具调用一样处理这些声明，跳过大部分 KV cache 读取。该方法在 15 个长上下文任务上进行了零样本测试，模型越大准确率损失越小。

reddit · r/MachineLearning · /u/eigenlaplace · 9月5日 06:07

**影响**: 短期内，现成的长上下文模型无需重新训练即可减少解码阶段的 KV cache 扫描，直接降低长对话或文档问答等任务的推理成本。长期来看，推理引擎可能采用这种声明式接口，训练阶段的稀疏注意力研究也可能进一步优化准确率与效率的权衡，影响长上下文 LLM 的实际部署方式。

**背景**: 基于 Transformer 的语言模型通常把之前 token 的 key 和 value 向量存入 KV cache，以便在自回归推理中复用。对于长上下文输入，全局注意力每生成一个新 token 都要读取整个缓存，成为计算瓶颈。思维链提示会要求模型先输出中间推理步骤再给出答案，而声明式注意力在这些步骤中加入声明来指示关注区域。
