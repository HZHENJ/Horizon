**Background**: A supply chain attack targets less secure elements in a software pipeline to compromise downstream users. ## [Monodratic: Learned Product-Hash Routing for Sparse Causal Attention](https://www.reddit.com/r/MachineLearning/comments/1vg3jda/monodratic_learned_producthash_routing_for_sparse/) ⭐️ 8.0/10

Monodratic proposes a learned product-hash routing mechanism for sparse causal attention, which selects relevant source blocks for each query to reduce computation while maintaining high accuracy. On an associative recall task, it achieves 99.35% mean accuracy compared to 19.66% for local-only attention. This work demonstrates that learned product-hash routing can achieve near-perfect accuracy on associative recall while significantly reducing attention computation. It offers a promising direction for scaling transformers to long sequences without compromising performance. The method uses RoPE, bounded causal posting lists, and product address probing to select remote source blocks, then performs exact causal softmax on a fixed-size set of tokens (local + remote). The implementation is a portable PyTorch mixer module; experiments are on synthetic associative recall tasks with no natural language tests. Scaling runs show a CPU timing exponent of 0.993, indicating near-linear scaling up to 32k tokens under fixed configuration.

reddit · r/MachineLearning · /u/dttdrv · Aug 5, 10:28

**Impact**: In the short term, this research provides a strong proof-of-concept for learned sparse attention, which may encourage further exploration and integration into open-source transformer frameworks. Longer term, if the method scales to natural language tasks and hardware-efficient kernels are developed, it could enable transformers to handle extremely long sequences with reduced computational cost, benefiting applications in long-document understanding, code generation, and multimodal AI.

**Background**: Sparse causal attention aims to reduce the quadratic cost of transformer self-attention by only attending to a subset of past tokens. Causal attention ensures each token only sees previous tokens. Product-hash routing is a hashing technique that maps high-dimensional vectors into a product of smaller hash codes, enabling efficient retrieval of relevant segments. Monodratic combines these ideas with learnable parameters to dynamically select which token blocks each query attends to.
