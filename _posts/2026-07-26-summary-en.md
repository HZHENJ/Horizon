The EU Commission has proposed replacing ubiquitous cookie consent banners with a system where users configure their privacy preferences once in the browser, which then automatically signals their choices to websites. This shift could make online consent more meaningful and user-friendly, addressing the failure of current banners to inform users. It reflects a push for more practical privacy regulations that work as intended. The proposal is still early-stage and needs legislative approval; technical specifics about browser settings and compatibility with GDPR are yet to be clarified. ## [Ruff v0.16.0 sharply increases default linting rules from 59 to 413](https://simonwillison.net/2026/Jul/25/ruff/#atom-everything) ⭐️ 7.0/10

Ruff v0.16.0, released on July 23, 2026, increased the default linting rule set from 59 to 413 rules, enabling detection of severe issues like syntax errors and immediate runtime errors without any configuration. This 7x expansion includes rules for common mistakes such as datetime without timezone, blind exception catching, and useless attribute access. This update significantly raises the baseline code quality for Python projects by catching a wide range of bugs out-of-the-box, but it breaks CI pipelines that use unpinned Ruff versions, forcing immediate developer intervention. It marks a major shift in the tool's philosophy, emphasizing proactive error detection over backward compatibility. Notable new default rules include DTZ005 (datetime.now() without timezone), BLE001 (catching blind Exception), and B018 (useless attribute access), many of which can be auto-fixed with `--fix --unsafe-fixes`, but some require manual edits. The total number of available rules grew from 708 to 968, indicating rapid development.

rss · Simon Willison · Jul 25, 22:44

**Impact**: In the short term, projects with unpinned Ruff dependencies will experience CI failures, requiring developers to fix hundreds of new lint warnings manually or with auto-fix tools. Long-term, this change may lead to fewer undiscovered bugs in the Python ecosystem, as more issues are caught early in development. The structured error output also facilitates AI-driven code fixes, potentially accelerating the cleanup process.

**Background**: Ruff is a fast Python linter and formatter written in Rust, widely used in the Python community. Linting rules flag potential errors and style issues; a 'default' rule set means those enabled without any project configuration. Previously, Ruff enabled only 59 rules by default, leading many projects to miss critical checks. Pinning dev dependencies (e.g., specifying exact versions) prevents unexpected breakage from updates.

## [Open-weight 4B Models Approach o3-Level Accuracy on Swedish Medical Exams](https://www.reddit.com/r/MachineLearning/comments/1v71wds/openweight_4b_models_approach_o3level_medical/) ⭐️ 7.0/10

**Impact**: In the short term, developers can build affordable, local medical QA applications for low-resource languages like Swedish without proprietary model access. **Background**: The Swedish medical licensing exam (MedQA-SWE) tests clinical knowledge in Swedish, a language estimated to be only ~1% of LLM training data. o3 is OpenAI's latest reasoning model that scored 88% on this benchmark.
