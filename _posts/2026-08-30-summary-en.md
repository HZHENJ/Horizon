## [AI Agents Make Novel Math Discoveries in Open-World Environment](https://www.reddit.com/r/MachineLearning/comments/1w2fl67/r_autonomous_mathematical_discovery_in_an/) ⭐️ 9.0/10

The paper introduces the Station, an open-world multi-agent environment where AI agents from different model families pursue a shared research goal without a central coordinator or scripted pipeline. On five of twelve AlphaEvolve construction problems and two case studies, these agents produced results novel relative to the literature, including a new infinite family of finite-field Kakeya sets, exact 604-point kissing configurations in dimension 11, new records for the discretized Kakeya needle and sign uncertainty problems, a substantially improved lower bound for Erdős's minimum-overlap problem, and novel infinite families for Book Ramsey numbers. This work is a major step toward truly autonomous AI-driven mathematical research, because the agents not only found numerical constructions but also generated theorems and analyses that make the results interpretable. By removing central coordination and allowing open-ended exploration, the Station demonstrates a path beyond narrow benchmarks toward AI systems that can contribute to open problems. The Station used AI agents from different model families with no central coordinator or scripted pipeline, and evaluated them on 12 construction problems from the AlphaEvolve catalogue plus two additional case studies. The agents produced not only numerical constructions but also theorems and analyses, and the authors released all raw agent dialogues, proofs, and verification code for transparency.

reddit · r/MachineLearning · /u/progenitor414 · Aug 30, 11:55

**Impact**: In the short term, mathematicians working on Kakeya sets, kissing numbers, and Erdős-type problems gain new constructions and sharper bounds they can directly build on, aided by the released dialogues, proofs, and verification code. Over the longer term, this open-world multi-agent setup could reshape mathematical research by enabling AI agents to collectively explore open problems, maintain shared literature, and generate interpretable theorems, accelerating discovery in combinatorics and geometric measure theory.

**Background**: A Kakeya set (or Besicovitch set) is a set in Euclidean space that contains a unit line segment in every direction; the Kakeya conjecture about the smallest possible size of such sets remains open in dimensions above three. The kissing number problem asks how many equal non-overlapping spheres can be arranged tangent to a central sphere in n-dimensional space. Erdős's minimum-overlap problem, proposed by Paul Erdős in 1955, is a problem in number theory and set theory that studies lower and upper bounds for a constant related to set overlaps.

## [QubesOS QSB-118: Dom0 Code Execution via Copy-to-VM Error Reporting](https://www.qubes-os.org/news/2026/08/29/qsb-118/) ⭐️ 8.0/10

On August 29, 2026, QubesOS published QSB-118 disclosing a critical vulnerability that allows arbitrary code execution in Dom0 via the qvm-copy-to-vm error reporting backchannel. The flaw is triggered when copying files from Dom0 to a qube; the VM variant of the tool is unaffected because its error reporting does not use system(). QubesOS relies on strong isolation between Dom0 and user-facing qubes, so arbitrary code execution in Dom0 breaks the core security guarantee. This finding is significant because it demonstrates that even a minimal, well-designed attack surface can harbor exploitable bugs in a security-critical OS. The vulnerable code path is in qvm-copy-to-vm's Dom0-side error reporting function, which calls system(); the tool uses the qfile protocol, a simplified archive format with simple file metadata. The VM variant of qvm-copy-to-vm does not use system() and is therefore not affected.

hackernews · vntok · Aug 30, 08:51 · [Discussion](https://news.ycombinator.com/item?id=49496918)

**Impact**: An attacker who can influence the file metadata or error messages during a Dom0-initiated copy-to-VM operation could execute code in Dom0, gaining control over the entire system and all qubes. Since Dom0 should not be used for routine work, the practical exposure is limited to users who copy files from Dom0, but the impact is severe for those affected. Over the longer term, this may drive further hardening of Dom0 tooling and reinforce advice against performing untrusted interactions from Dom0.

**Background**: QubesOS is a security-oriented desktop operating system that isolates tasks into separate virtual machines called qubes. Dom0 is the privileged administrative domain that manages the system and has control over all other qubes, so compromising Dom0 is equivalent to compromising the entire machine. The qvm-copy-to-vm command copies files from Dom0 to a target qube using the qfile protocol, a simple archive format with file metadata. Error reporting in this command is a backchannel that reports failures during the copy process.

## [Tencent Releases Hy4 Preview: 770B Open-Weight LLM with 1M Context](https://simonwillison.net/2026/Aug/29/hy4/) ⭐️ 8.0/10

Tencent released Hy4 Preview, an open-weight text-only LLM with 770B total parameters, 49B active parameters, and a 1M-token context window. Its chat template supports two reasoning_effort levels—'high' (default) and 'no_think'—and Simon Willison's test generated an SVG of a pelican riding a bicycle. This is a significant open-weight release that substantially increases scale compared with Tencent's earlier Hy3 (295B total, 21B active, 256K context), signaling rapid progress in large MoE models and long-context capabilities. The chat template's explicit reasoning control also gives developers a clearer way to toggle reasoning behavior. Hy4 Preview is a Mixture-of-Experts model with 770B total and 49B active parameters, so only a subset of parameters are used per token. Its chat_template.jinja raises an exception if reasoning_effort is set to any value other than 'high' or 'no_think', and Willison observed that the reasoning trace uses slightly truncated English likely for token efficiency.

rss · Simon Willison · Aug 29, 23:53

**Impact**: In the short term, developers can access Hy4 Preview via OpenRouter or download the 1.56TB checkpoint from Hugging Face, though the 770B total parameter size means local deployment will require substantial GPU memory, so most early use will be through hosted APIs. The model's 1M-token context window opens up long-document analysis and extended agentic workflows, but the text-only design leaves vision tasks unaddressed. Over time, this release raises the bar for other open-weight labs and could accelerate support for very large MoE models and reasoning-effort controls in tooling and libraries.

**Background**: Open-weight models make their trained weights publicly available, allowing anyone to download and run them, though licensing terms may still apply. In a Mixture-of-Experts (MoE) architecture, the model contains many expert sub-networks, and a router selects a small number to process each token; total parameters describe the full model size, while active parameters are those used per token and determine compute cost. A chat template is a Jinja-based script that formats conversations and special tokens for a model, and it can also expose sampling options such as reasoning effort. Tencent's previous Hy3 model had 295B total parameters, 21B active parameters, and a 256K context window.
